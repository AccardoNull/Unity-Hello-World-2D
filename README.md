# Inventory-And-Shop-System

Live WebGL Demo link: [https://accardonull.github.io/Inventory-and-Shop-System/](https://accardonull.github.io/Inventory-and-Shop-System/)

Control: 

Arrow keys: horziontal movement

Space : jump 

Z : Open trade menu and pick up items

Project Overview:

- A portable software package of a modular in-game trading system built using C# and Unity Engine to support highly customizable frameworks for inventory storage. virtual shops and in-game purchases. 

- Created and maintained detailed technical documentation to outline system configurations, technical solutions, and operational procedures. Implemented real-time data updates and UI synchronizations using delegate callback functions to ensure data consistency and accuracy across integrated systems. 

- Provided clear demonstration of problem space, motivations, solution overview and challenges using PowerPoint slides and embedded video presentations.
